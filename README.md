# CreatorOS Dashboard

这是一个无需构建、无需服务器的静态网站；入口文件是 `index.html`。

## 最快上线：Netlify Drop

打开 https://app.netlify.com/drop ，把整个 `creatoros-site` 文件夹拖进去。发布完成后会立即得到一个可分享的网址。

## Vercel

在 Vercel 导入此文件夹或其 Git 仓库。无需配置构建命令，输出目录保持项目根目录。

## GitHub Pages

将此文件夹内容推送到 GitHub 仓库根目录，在仓库 Settings → Pages 中选择从分支部署，目录选 `/ (root)`。

## 注意

页面的字体通过 Google Fonts 加载。若部署环境无法访问 Google 服务，页面仍可使用系统字体正常显示。
